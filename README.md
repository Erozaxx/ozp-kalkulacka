# Kalkulačka povinného podílu OZP

Jednostránková kalkulačka povinného podílu zaměstnávání osob se zdravotním postižením (zákon č. 435/2004 Sb., § 81 až 84). Spočítá povinný počet OZP, odvod do státního rozpočtu, orientační cenu zaměstnání a náhradní plnění, včetně kombinace.

Výsledek je orientační. Pravidla a zdroje jsou v patičce stránky. Připravila TSP DATA.

Stránka: https://erozaxx.github.io/ozp-kalkulacka/
